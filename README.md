To open the website, use the main page. 

You need to create a file with your API KEY to use WebApp. 
Therefore create a folder called .streamlit and in this folder a file called secrets.toml like this:
\task1-template\task1-template\.streamlit\secrets.toml
In this file you have to add your API as followed
  LLM_API_KEY = "Your Key here"

Information concerning the stats:
  after submitting your guess or the give up button, you have to wait a second before changing to the stats page.
  So either wait for the ballons to dissapear or a second.

The correct branch is the new-main-branch. The py documents are in the task1-template order.
